# 🩺 MediBooking - Responsive Clinic Booking System

A modern, interactive, and responsive web application designed for booking clinic appointments. Built with **Vanilla JavaScript**, **HTML5**, and **Tailwind CSS**, this platform allows patients to learn about the clinic, browse expert doctors, pick available time slots, and confirm their medical appointments seamlessly.

---

## ✨ Features

- **Interactive Navigation & Hero Section:** Clean header and an "About Clinic" section highlighting statistics, emergency contacts, and clinic values.
- **Dynamic Doctor Selection:** Cards grid showcasing available specialists with details like image, rating, specialization, and consultation fee.
- **Real-Time Time Slot Generator:** Selecting a doctor dynamically loads and displays their specific available time slots.
- **Live Booking Summary:** Instant visual feedback updating the selected doctor, date, time, and total consultation price in real-time.
- **Form Validation & Confirmation:** Handles patient details input (Name, Phone Number) before finalizing the appointment booking.
- **Fully Responsive Design:** Tailored with Tailwind CSS to ensure a smooth layout across mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS (Utility-first styling with responsive grid layouts)
- **Logic & DOM Manipulation:** Vanilla JavaScript (ES6+ State Management & Event Handling)
